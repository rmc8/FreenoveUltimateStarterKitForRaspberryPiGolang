## 1. Go 言語の基本ルール

Go 言語には、シンプルで厳格なルールがいくつかあります。

### `package main` (パッケージ宣言)
Go のプログラムは必ず「パッケージ」という単位で管理されます。
- `package main` と書かれたファイルは、**「これは実行可能なプログラムですよ」** という合図です。

### `import` (外部ライブラリの取り込み)
他の人が作った便利な機能（ライブラリ）を使うための宣言です。
- 今回は標準ライブラリの `fmt` (画面出力) や `time` (時間待ち) に加え、`periph.io` というハードウェア操作用の外部ライブラリを取り込んでいます。

### `func main()` (エントリーポイント)
プログラムが実行されたとき、**一番最初に呼ばれる場所**です。
- Go では `main` パッケージの中の `main` 関数からすべてが始まります。

## 2. コードの詳細解説

今回の `main.go` の中身を一行ずつ見ていきましょう。

### ハードウェアの初期化
```go
if _, err := host.Init(); err != nil {
    panic(err)
}
```
- **`err`**: Go では「エラーが起きたかどうか」を関数の戻り値として受け取ります。
- **`if err != nil`**: 「もしエラーが `nil` (空) でなければ」という意味で、Go で最もよく使われるエラー処理のパターンです。
- **`panic(err)`**: 修復不可能なエラーが起きたときにプログラムを強制終了させます。

### ピンの指定
```go
p := gpioreg.ByName("GPIO17")
```
- **`:=`**: 変数の宣言と代入を同時に行う便利な記法です。Go が右側の値から型を推論してくれるので、型名を省略できます。

### 無限ループ
```go
for {
    // ... 処理 ...
}
```
- `for` だけを書くと、**「ずっと繰り返す」** という無限ループになります。L チカのような、ずっと動き続けるデバイスの制御によく使われます。

### 電圧の切り替え
```go
p.Out(gpio.High) // 電圧をかける（LED ON）
p.Out(gpio.Low)  // 電圧を下げる（LED OFF）
```
- `gpio.High` は内部的には「1」、`gpio.Low` は「0」のような値ですが、読みやすさのために名前がついています。

## 3. なぜ Raspberry Pi 向けに「ビルド」が必要なのか？

あなたの PC（Ubuntu など）と Raspberry Pi では、脳みそにあたる CPU の種類が違います。
- **PC**: x86_64 (Intel/AMD)
- **Raspi**: ARM64

Go は **「交差コンパイル (Cross Compilation)」** が非常に得意な言語です。
`GOOS=linux GOARCH=arm64` という環境変数を指定するだけで、PC 上にいながら Raspberry Pi 用の実行ファイルを一瞬で作ることができます。これが Go が IoT 分野で人気の理由の一つです。
